# food-order｜互動式點餐網站

以 **HTML、CSS、原生 JavaScript** 製作的點餐介面，展示瀏覽菜單、加入購物車、折扣計算及模擬結帳流程。

## 核心功能
- **購物車：** 商品分類篩選、加入商品、數量增減、刪除及金額即時計算。
- **折扣機制：** 消費滿 NT$300 折 NT$30；限時小遊戲可取得最高 NT$100 折扣。
- **資料保存：** 使用 `localStorage` 保存購物車與折扣資訊。
- **介面互動：** 行動版購物車摘要、商品圖片放大預覽及結帳提示視窗。

## 技術
HTML、CSS、JavaScript、DOM 事件處理、localStorage。

## 如何體驗
下載或 Clone 專案後，開啟 `index.html`，即可進入網站操作。

```bash
git clone https://github.com/zoey0603/food-order.git
```

> **結帳僅為前端模擬**，沒有實際付款、後端訂單資料庫或金流串接。遊戲次數與折扣資訊由瀏覽器本機保存。

**作品定位：** 前端互動與 JavaScript 練習專案。
